# هسته HTTP/API بک‌اند Node — بسته اولیه نشانه‌ها

نگه‌دارنده: @omidkh68 · اولویت P0 · #33، #66 · [English](backend-core.md)

## قرارداد

بسته backend-core نسخه ۱ روی مؤلفه‌های Backend انتخاب‌شده با محدوده صریح و حل‌شده که از نشانه Manifest مربوط به NestJS، Express، Fastify، Koa یا Hono کشف شده‌اند عمل می‌کند. چهار نشانه متنی موجود در فایل‌های .js، .ts، .mjs و .cjs با شناسه Rule ثابت و بدون تغییر شناسه و عنوان تاریخی کنترل دوباره استفاده می‌شوند. اسکن قدیمی بدون محدوده بدون تغییر می‌ماند.

| شناسه Rule | کنترل تاریخی | Candidate |
|---|---|---|
| BACKEND.HTTP.CORS_WILDCARD | API-02 | پیکربندی Origin با Wildcard |
| BACKEND.HTTP.ERROR_DISCLOSURE | API-10 | پاسخ شامل Stack یا پیام خطا |
| BACKEND.HTTP.FORWARDED_HEADER | API-15 | خواندن هدر Forwarded نیازمند بررسی اعتماد |
| BACKEND.API.PRIVILEGED_FIELD | BIZ-02 | ویژگی درخواست نیازمند بررسی مجوز در سطح فیلد |

مؤلفه‌های غیر Nest در اسکن محدوده‌دار، دو نشانه قدیمی Whitelist مربوط به ValidationPipe یا بخش اختصاصی enableCors() خالی از قاعده CORS را دریافت نمی‌کنند. در Nest قاعده اصلی روی پسوندهای قدیمی خود معتبر می‌ماند؛ فقط تطابق Wildcard شناسه قاعده مشترک CORS را دریافت می‌کند. نشانه SQL خام Prisma همچنان نشانه تاریخی جداگانه است و عضو این بسته نیست. سایر خانواده‌های قواعد محدوده‌دار قبلی حفظ می‌شوند.

## استفاده و شواهد

```bash
python3 <skill-dir>/scripts/security_scan.py --root . --profile backend --format json
```

خلاصه شامل شناسه و نسخه backend_core، ریشه‌های انتخاب‌شده، تعداد فایل‌های واجد شرایط بررسی‌شده و تعداد تطابق هر Rule است. Candidateهای مشترک دارای pack_id، pack_version، rule_id و نگاشت LEGACY_COMPATIBILITY هستند. قطعه کد و مقادیر سورس بازگردانده نمی‌شوند. سقف‌های قبلی پوشش فایل و سیگنال اعمال می‌شوند. Tracker کلید تاریخی Candidate را حفظ می‌کند؛ کاربردپذیری کنترل غیر Nest همچنان NEEDS_DISCOVERY است، نه کنترل تأییدشده.

## محدودیت‌ها و اعتبارسنجی

این بررسی Regex آفلاین است، نه Parser، موتور جریان داده، اثبات مجوز، تست مرورگری CORS یا Adapter اختصاصی فریم‌ورک. Wildcard ممکن است عمدی، هدر Forwarded مورد اعتماد و فیلد درخواست اعتبارسنجی‌شده باشد. نبود تطابق هرگز امنیت را اثبات نمی‌کند. فقط مالکیت مؤلفه انتخاب‌شده تعیین می‌شود؛ مرز Client/Server در سطح فایل برای مؤلفه مختلط اثبات نمی‌شود. بک‌اندهای غیر Node تحت پوشش این بسته نیستند. کشف فناوری نسخه نصب‌شده فریم‌ورک یا پوشش کامل امنیتی را تأیید نمی‌کند. قواعد عمومی و تاریخی قبلی ممکن است خارج از بسته جدید همچنان Candidate تولید کنند.

Fixtureهای مصنوعی پنج خانواده Manifest، جایگزین‌های امن، جداسازی محدوده، تفکیک قواعد Nest، هویت تاریخی و عدم افشای سورس را پوشش می‌دهند. اعتبارسنجی بسته، مجموعه کامل تست آفلاین Python و بررسی tarball npm را اجرا کنید. برای Rollback تغییر مستقل را بازگردانید؛ مهاجرت Ledger لازم نیست. Adapterهای تخصصی فریم‌ورک و اندازه‌گیری کیفیت تشخیص مراحل جداگانه هستند.
