# Mobile synthetic control review (#151)

[فارسی](mobile-control-review-FA.md)

Run `python3 <skill-dir>/scripts/security_mobile_control_review.py --reference MASVS-PRIVACY-4 --policy policy.json --observations observations.json` (also supports `MASVS-RESILIENCE-4`). Policy fields: `schema_version: 1`, `synthetic_only: true`, `reference`, `signal_policy` (empty for PRIVACY-4; for RESILIENCE-4, map `INTEGRITY_SIGNAL_ABSENT`, `INTEGRITY_SIGNAL_INVALID`, `INTEGRITY_SIGNAL_REPLAYED` to DENIED, STEP_UP or RESTRICTED). Observations contain `schema_version: 1`, `synthetic_only: true`, `policy_sha256` of exact policy bytes and `observations` rows with `scenario`, `decision` and distinct `evidence_sha256`. See the source CASES for required scenario IDs. The reviewer covers access, correction, deletion, withdrawal, renewed consent and illustrative integrity-response observations including independent server authorization. Missing or contradictory observations fail; raw evidence is not inspected. These are deliberately bounded synthetic reviews, not real device tests, independently verified evidence, normative mapping or compliance. A matching observation does not prove resilience or effective privacy rights. CI pending.
