# هسته مستقل از فریم‌ورک وب — بسته اولیه نشانه‌ها

نگه‌دارنده: @omidkh68 · اولویت P0 · Issueهای #33 و #62 · [English](web-core.md)

## قرارداد

در حالت محدوده صریح و حل‌شده، مؤلفه‌های Frontend انتخاب‌شده با نشانه Manifest مربوط به Angular، React، Next.js، Vue، Nuxt، Svelte یا SvelteKit بسته web-core نسخه ۱ را دریافت می‌کنند. سه عبارت موجود مرورگر روی سورس JS/JSX/TS/TSX/MJS/CJS دوباره استفاده می‌شوند. هیچ نسخه فریم‌ورکی تأیید نمی‌شود. اسکن قدیمی بدون محدوده و کلیدهای تاریخی یافته بدون تغییر می‌مانند.

| شناسه Rule | کنترل تاریخی | نشانه |
|---|---|---|
| WEB.DOM.INNER_HTML | ANG-01 | انتساب مستقیم innerHTML، شامل حالت محدود دو خط مجاور موجود |
| WEB.STORAGE.TOKEN | ANG-04 | دسترسی به local/session storage مرورگر با نام توکن مشابه اسرار |
| WEB.NAV.DYNAMIC | ANG-11 | ناوبری پویای location مرورگر |

شناسه و عنوان تاریخی برای سازگاری با کاتالوگ ۱۴۵ کنترل و Tracker ثابت می‌مانند. سیگنال مشترک اثبات کاربرد کنترل اختصاصی Angular در فریم‌ورک دیگر نیست. کاربردپذیری غیر Angular همچنان NEEDS_DISCOVERY است؛ دلیل، نگاشت مشترک را شرح می‌دهد. قواعد اختصاصی Sanitizer/Template انگولار در سایر فریم‌ورک‌ها فعال نمی‌شوند.

## استفاده و شواهد

```bash
python3 <skill-dir>/scripts/security_scan.py --root . --profile frontend --format json
```

خلاصه شامل شناسه/نسخه بسته web_core، ریشه مؤلفه انتخاب‌شده، تعداد فایل واجد شرایط بررسی‌شده و شمارش Rule است. هر Candidate مشترک دارای فراداده pack_id، pack_version، rule_id و نگاشت LEGACY_COMPATIBILITY است. سقف پوشش اسکن/سیگنال و شمارش فایل‌های حذف‌شده قبلی اعمال می‌شوند؛ تعداد Rule معیار پوشش آسیب‌پذیری نیست. Tracker هویت قبلی Candidate را وارد می‌کند، نه تأیید یا شناسه کنترل جدید.

## محدودیت‌ها و گام بعد

این بررسی اکتشافی Regex آفلاین است، نه Parser، تحلیل Taint، SSR یا مرز Client/Server. قالب Vue/Svelte، API رندر اختصاصی JSX، Stack ناشناخته، مؤلفه صرفاً سروری و موبایل بومی در این بسته نیستند. مؤلفه چندفریم‌ورکی در سطح ریشه مؤلفه محدود می‌شود، نه طبقه‌بندی اثبات‌شده فایل مرورگر/سرور. انتساب امن ممکن است همچنان تطابق داشته باشد؛ نبود Candidate هرگز امنیت را اثبات نمی‌کند. کد اجرا یا ویرایش نمی‌شود و مقادیر سورس چاپ نمی‌شوند.

Fixtureهای مصنوعی مثبت/منفی خانواده‌های کشف، جداسازی محدوده، چندخطی، کلید ثابت و محدودیت قالب را پوشش می‌دهند. اعتبارسنجی بسته و مجموعه کامل تست آفلاین را اجرا کنید؛ بررسی بسته npm باید موفق شود. در صورت نیاز تغییرات مستقل را بازگردانید؛ مهاجرت Ledger لازم نیست. Adapterهای تخصصی Frontend، قواعد مشترک Backend، تحلیل معنایی و اندازه‌گیری دقت در مراحل بعدی هستند.
